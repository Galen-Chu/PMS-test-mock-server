 │ V │ checkInSerial │ String │ 住客序號

 │  │ checkOutRemark │ String │ 退房提醒
 │  │ sumItemTotal │ Number │ 已消費總額
 │  │ sumAdvcTotal │ Number │ 已預收金額
 │  │ preCreditAmount │ Number │ 已預授權金額
 │  │ groupNos │ String │ 團號
 │  │ chargeInfo │ String │ 不可掛帳的原因
 │  │ ciDate │ Date │ C/I 日期
 │  │ coDate │ Date │ C/O日期
 │  │ ikey │ String │ 訂房卡號
 │  │ sexType │ String │ 性別:M:男 F:女 U:未定義 S:保密

 │ 必填 │ Json名稱 │ 型別 │ 說明

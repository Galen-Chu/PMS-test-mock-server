訊息交換呼叫方式
HTTP執行流程(HTTP GET)
德安網址?athena=25&hotel=01&thirdParty=TT&TxnData=<XML>&Randomstr=1&istom=1
紅字區段由德安提供給廠商。
實際串接URL於客戶環境準備好需測試時再提供。
Parameter:
athena:由德安提供客戶固定代號(必填)
hotel: 由德安提供客戶固定代號(必填)
thirdParty:由德安提供該廠商固定代號(必填)
TxnData: 訊息之XML內容(必填)
Randomstr: 預設1,隨機字串(避免Browser Cache)
istom: 預設1(TxnData使用URLEncode), 4(TxnData使用Base64)
廠商須提供一個URL，接收德安傳送的入住、退房、換房資訊
舉例說明，IPTV提供URL ：
接收C/I ，取得住客姓名等資訊，於IPTV系統自行決定呈現的歡迎詞
接收C/O，清除房間的住客姓名等資訊

B4: 房況變化告知
時機：當房況有變化時，主動通知PMS
發送端發送XML規格說明
欄位說明：
┌─TABLE─┐
 │ 欄位代號 │ TYPE │ 中文說明 │ 內容說明
 │ REVE-CODE │ CHAR(10) │ 訊息代號 │ 固定值：0300TT4190
 │ ROOM_NOS │ CHAR(6) │ 房號 │ 
 │ INS_CARD_INF │ CHAR(20) │ 插卡資訊 │ 
 │ INS_CARD_NO │ CHAR(20) │ 插卡卡號 │ 
 │ ACTION_COD │ CHAR(200) │ 動作說明 │ CLEAN：清掃 見房間房況備註順序9 DND  ：勿擾 見房間房況備註順序10 DOOR：門  見房間房況備註順序11 EMG：緊急壓扣 見房間房況備註順序8 MAIN_POWER :總電源 見房間房況備註順序4 #ROOM_STA#ROOM_STA值#：見房間房況備註 #RMTEMP#房間室溫值#：現在室溫值(A7使用)，溫度值最多十個字，由廠商決定內容。
 │ ACTION_STA │ CHAR(1) │ 動作狀態 │ 1：設定     0：清除 請依房間房況設定中的對應值來設定 EXAPLE: 勿擾0=關，1=勿擾開啟 緊急按鈕0 = 動作，1 = 無動作 房門    0 = 門開，1 = 門關 房間清潔1 = 請打掃， 2 = 打掃中3 = 待巡房 4= 巡房中0 = 清潔完成 德安接到0時會設定為乾淨房，其他都在德安設定/顯示為髒房。
 │ ACTION_DAT │ CHAR(21) │ 觸發時間 │ FORMAT：YYYY/MM/DD HH24:MI:SS
└───────┘
